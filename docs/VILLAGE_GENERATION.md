# 村の規模と生成密度

Mura Musubiは、バニラ村を置き換えずに大規模な村を追加生成します。

## 生成設定

- バニラ村: Minecraft標準のまま（ジグソー深度6、間隔34チャンク）
- 大規模村: ジグソー深度10、最大半径112ブロック、間隔20チャンク
- 通常の村から8チャンク以内には大規模村を生成しない
- 平原、砂漠、サバンナ、雪原、タイガの5種類に対応

大規模村も `minecraft:village/*` のバニラ建物プールを使用します。新しい家、職業施設、装飾などは追加しません。同じ建物群がより多く接続されることで、規模だけを大きくします。

## 適用範囲

村の生成変更は、新しく生成されるチャンクにだけ適用されます。すでに探索済みの場所に村は追加されません。確認するときは、新規ワールドを作成するか、既存ワールドの未探索地域へ移動してください。

大規模村は `#minecraft:village` タグへ追加されるため、Mura Musubiの自動検出と道路接続の対象になります。

## 互換性

バニラの村定義は上書きしません。ただし、村の構造タグや構造セットを変更する他のワールド生成MOD・データパックとは、生成密度が意図より高くなる可能性があります。
